# Desafios 200

Resoluções do curso **200 Desafios SQL Super Prática**, de Reginaldo Junior.

Banco usado: **PostgreSQL**.

## Como organizo

Um arquivo por desafio, em blocos de dez:

```
desafios-200/
├── 001-010/
├── 011-020/
└── ...
```

## Formato de cada arquivo

```sql
-- Desafio 007
-- Pergunta: qual o total vendido por categoria no ultimo trimestre?
-- Conceito: GROUP BY com filtro de data

SELECT ...
```
