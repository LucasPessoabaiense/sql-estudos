# sql-estudos

Meu caderno de SQL. Aqui ficam os exercícios que resolvo, as anotações do que aprendo e os desafios do curso que estou fazendo.

Banco principal dos estudos: **PostgreSQL**. Onde a sintaxe muda em outros bancos, eu anoto.

## Como está organizado

| Pasta | Conteúdo |
|---|---|
| [01-ddl-dml](01-ddl-dml) | Criação de tabelas, inserção, atualização e exclusão |
| [02-joins](02-joins) | INNER, LEFT, RIGHT, FULL e self join |
| [03-agregacoes-group-by](03-agregacoes-group-by) | COUNT, SUM, AVG, GROUP BY e HAVING |
| [04-subqueries-ctes](04-subqueries-ctes) | Subconsultas e CTEs |
| [05-window-functions](05-window-functions) | ROW_NUMBER, RANK, LAG, LEAD e SUM OVER |
| [06-performance-indices](06-performance-indices) | Índices, plano de execução e otimização |
| [desafios-200](desafios-200) | Resoluções do curso 200 Desafios SQL |
| [notas](notas) | Anotações e resumos |

## Regras que sigo aqui

- Cada pasta tem um README explicando o conceito em poucas linhas
- Cada arquivo .sql começa com um comentário dizendo qual pergunta ele responde
- Se travei em algo, escrevo onde travei e o que resolveu

Este repositório é estudo, não vitrine. É pra eu voltar aqui daqui a um ano e entender o que eu quis dizer.
