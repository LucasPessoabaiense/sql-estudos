# 01 - DDL e DML

**DDL** define a estrutura do banco: `CREATE`, `ALTER`, `DROP`.
**DML** mexe nos dados: `INSERT`, `UPDATE`, `DELETE`.

## O que pratico aqui

- Criar tabelas com os tipos certos e restricoes que evitam sujeira no banco
- Chave primaria, chave estrangeira, NOT NULL e UNIQUE
- Inserir, atualizar e apagar com seguranca, testando o WHERE antes de rodar

## Regra que sigo

Todo arquivo .sql daqui comeca com um comentario dizendo o que ele faz.
