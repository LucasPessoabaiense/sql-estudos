# Notas

Anotações soltas, resumos e coisas que quero lembrar depois.

O estudo bruto fica no meu Obsidian. O que chega aqui é o que já está entendido e escrito de um jeito que outra pessoa consegue ler.

## Tipos de nota que guardo aqui

- Resumo de um conceito, escrito com minhas palavras
- Erro que cometi e como descobri o que era
- Comparação entre formas diferentes de resolver a mesma coisa
- Diferenças de sintaxe entre PostgreSQL, MySQL e SQL Server
